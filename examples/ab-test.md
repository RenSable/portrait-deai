# 实测 A/B：同一类人像需求，常规写法 vs 本手册方法

## A 组（常规写法）

出来的是一张影楼式头像：

- 白衬衫、纯灰背景、正对镜头，标准证件照/形象照构图
- 皮肤光滑发亮，没有毛孔与瑕疵，肤色均匀
- 五官完全对称，瞳孔大而圆，露齿笑弧度标准
- 均匀打光，脸上没有阴影过渡
- 头发根根服帖，像刚做完造型

单看挑不出错，但每一项都是模型的默认造假点：这是一张「不会出现在任何人手机相册里」的脸。

## B 组（本手册方法）

方法构成：以 [Playbook 01](../playbooks/01-quick-fix.md) 为主——① 定调（手机拍、真实存在的人）、⑯ 皮肤（毛孔、绒毛、红晕）、⑳ 收尾（不完美优先），场景换成生活切片（清晨卧室窗边、刚睡醒），光只给单侧窗光。

出来的是一张窗边自拍感的人像：

- 皮肤能看到毛孔、雀斑与零星小痣，肤色不均，脸颊带自然红晕，唇部有干纹
- 头发蓬乱，碎发与胎毛四处翘起，不是服帖的造型感
- 视线偏向一侧，不直视镜头；表情是微微抿嘴，不是摆拍笑
- 双眼与眉形有自然的左右差
- 背景是没叠的被子、杂物与窗帘，生活现场而不是影棚
- 光从左侧窗口单侧进来，脸上有真实的明暗过渡

## 逐项对照

| 看哪处 | A 组 | B 组 |
|---|---|---|
| 皮肤 | 光滑发亮、无毛孔 | 毛孔、雀斑、小痣、油光不均 |
| 肤色 | 全脸均匀一色 | 不均 + 自然红晕 + 阴影过渡 |
| 头发 | 根根服帖 | 碎发、胎毛、发束参差 |
| 眼睛 | 瞳孔大而圆、左右等大 | 大小自然、带左右差 |
| 表情 | 标准露齿笑、正视镜头 | 微抿嘴、视线移开 |
| 光 | 均匀无影 | 单侧窗光、柔和阴影 |
| 场景 | 纯色背景影棚感 | 卧室生活现场（被子、杂物、窗帘） |
| 第一印象 | 广告/形象照 | 会发在社交平台上的随手自拍 |

## 复现要点

1. B 组的关键不在换主体，而在**换默认项**：介质从「相机写真」换成「手机随手拍」，场景从影棚换成带时间状态的生活切片（刚睡醒 + 窗边 + 清晨）。
2. ⑯ 是杀伤最大的一句：毛孔、绒毛、红晕、自然阴影四个词同时出现，磨皮感基本消失。
3. 如果 B 组方向过头（太憔悴、太脏），不要删真实句，加 ③ 刹车：「在保持美感的同时，不要把脸和皮肤修得过于完美」。
4. 想进一步压掉「成像假」，再叠 [Playbook 02](../playbooks/02-lens-card-defects.md)：先删 8K/超写实，光源写清并注明没有其他补光，缺陷挑噪点与浅景深两类即可。

> 口径说明：本组为单组实测对照，不同模型、不同主体上效果会有差异；原作者（@wanerfu）的「消掉九成」是其本人宣称，本仓不背书具体百分比，只记录我们这组里逐项可辨的差别。
