# Playbook 03 · 深度姿势 + 三槽配方：一张参考只管一个属性

> 方法来源：深度姿势法 @94vanAI；三槽配方 @Alexvhyn。本篇是两者的合并用法。
> 适用：要指定姿势、要同一个角色换装/换场景、带参考图生成时。纯文字出图不需要这一篇，先用 Playbook 01。

## 为什么姿势要用深度图，不用线稿

线稿/骨架图只有线条，没有前后与体积：哪只手在前、腿往哪个方向弯，模型只能猜，猜错就是肢体穿插、正反颠倒。

**深度姿势图**是灰色无面人体模型的渲染图，亮度即距离（越白越靠近镜头）。它同时告诉模型三件事：姿势、每个部位的前后层级、身体的体积感。生成的人物更立体，姿势还原度也高得多。

## 三槽配方：参考图的分工

一张参考图只许贡献**一个**属性，这是整套方法的纪律核心——不分工，参考图会互相串味：姿势图的体型跑到人物身上、服装图的模特脸混进你的角色。

| 槽 | 放什么图 | 只取 | 明确不要 |
|---|---|---|---|
| 人像槽 | 人物/身份参考图 | 脸、特征标记（如痣、疤）、体型 | — |
| 姿势槽 | 深度姿势图 | 姿势与骨架 | 模型人的体型、颜色、材质 |
| 服装槽 | 服装参考图 | 服装款式（outfit）本身 | 模特本人、背景 |

## 操作步骤

### 第 1 步：选姿势，只下这一张

1. 在深度姿势图库里按动作找姿势（如 POSE-DB-02：ai-pose-depth-gallery.pages.dev，一个姿势通常配多个角度，共 288 个姿势 / 1,439 张深度图）。
2. 选定角度后，**只下载这一个姿势的原图 PNG**。
3. 同一个系列要保持姿势一致，就复用同一张深度图。

> 图库规矩：禁止批量下载与再分发图库的图片数据。一次一张、只作生成参考，是这条方法的合规用法。

### 第 2 步：备齐另外两槽

- 人像槽：一张能看清脸与体型的参考图。想要皮肤真实感，这张图本身就该选带真实皮肤质感的（毛孔、自然光），别拿磨皮网红图当身份参考——参考图的质感会被带进结果。
- 服装槽：一张服装图（商品图、平铺图、模特图都行，反正只取款式）。没有服装参考时，服装改用文字写在提示词里，不占槽。

带服装参考时有个省事路线：用三槽拼图工作台（如 ai-pose-gallery.anhao.app 的组装功能）把人像/姿势/服装三槽拼成一张配方图，再整张喂给生成器。

### 第 3 步：组装提示词——正文只写三件事

分工之后，提示词正文**不再描述脸、姿势、服装**，只写：

1. **环境**：地点、时间、场景里有什么
2. **光线**：光源与方向（可叠 Playbook 02 的光源清单）
3. **构图**：景别、机位、人物在画面中的位置

外加**每张参考图一条范围说明**，把「只取什么、不要什么」说死：

```
参考图 1 只用于脸部特征与体型，不取其服装与背景；
参考图 2（深度图）只用于姿势与骨架，不取模型人的体型、颜色与材质；
参考图 3 只用于服装款式，不取模特本人与背景。
环境：清晨的卧室窗边，背景有没叠的被子和窗帘；
光线：左侧窗口进来的自然光，单侧光，脸上柔和的阴影过渡；
构图：近距离半身，略带倾斜的随手拍取景。
```

### 第 4 步：真实感锚点归人像槽

Playbook 01 的锚点句（皮肤、毛孔、红晕）属于**人像属性**。用三槽时，把它写进人像槽的范围说明后面，或单列一段「真实感」——不要散落在正文里，否则会污染姿势槽与服装槽的权重：

```
参考图 1 只用于脸部特征与体型；皮肤保留真实毛孔与细微瑕疵，脸颊带自然红晕，没有磨皮和美颜滤镜。
```

## 常见翻车与对策

| 翻车 | 原因 | 对策 |
|---|---|---|
| 人物长了模型人的灰色质感 | 姿势槽没写排除项 | 范围说明里明确「不取颜色与材质」 |
| 脸变成了服装模特的脸 | 服装槽串味 | 明确「只取服装款式，不取模特本人」 |
| 姿势对了但体型变了 | 姿势图体型压过人像槽 | 明确姿势槽「不取体型」，人像槽声明体型以图 1 为准 |
| 换了几张图都是同一张「网红脸」 | 只用最热门的参考图 | 换冷门参考；去老杂志、街景、生活照片里找脸与瞬间（原作者提醒：图库是起点，不是标准答案） |
| 皮肤又变塑料 | 身份参考图本身是磨皮图，或锚点没归槽 | 换真实质感的身份参考；按第 4 步补锚点 |

## 检查清单

- [ ] 姿势用的是深度图，不是线稿/骨架图；只下载了选中的一张
- [ ] 三个槽各就各位，每张参考图都有一条范围说明（只取什么 + 不要什么）
- [ ] 正文只写了环境、光线、构图，没有重复描述脸/姿势/服装
- [ ] 真实感锚点写进了人像槽一侧，没有散落在正文
- [ ] 同系列复用了同一张深度图保姿势一致
