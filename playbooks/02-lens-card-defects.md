# Playbook 02 · 镜头卡缺陷清单：先布光，再加缺陷

> 方法来源：@Cara_Mosquito《你生成的图 AI 味太重是因为「太完美了」》（X 长文，2026-11-09）。作者是影视合成师，本文模板与清单按其原版整理，案例提示词为其原文。
> 适用：人像已过 Playbook 01、但画面整体仍像 CG/海报——夜景、逆光、带环境的画面尤其明显。

## 病根

真实摄影机的画面处处有缺陷：高光会溢出、镜头会眩光、胶片有颗粒、焦点只有一个薄平面、远处有空气。AI 画面假，是因为这些全被「优化」掉了。合成师的工作就是把缺陷加回去——**AI 负责干净，你负责「脏」，坏得恰到好处，坏得像真的。**

## 第一步：删词

写提示词前先删掉这些求完美的词，它们与去 AI 味的目标正好相反：

> 8K、超高清、超写实、极致细节、大片质感、史诗级

改去描述：画面哪里不完美、怎么不完美。

## 第二步：按镜头卡顺序写（不可颠倒）

顺序是因果链：人物 → 光源 → 缺陷 → 调度。**几乎所有缺陷都由光引起**：光源栏里没有灯，缺陷栏写了眩光/光晕/光斑，模型只能乱猜。

```
【人物锁定】
[角色]：[服装、发型、关键特征]。以下画面中服装保持不变。

【光源清单】
[时间、地点]。
主光：[来自哪个方向、什么颜色、软还是硬]。
点光源：[画面里能看到的灯：路灯、车灯、警示灯、屏幕、指示灯、火苗]。
没有其他补光。

【缺陷清单】（从五类里挑 2–3 类，写清具体样子）

【调度与表演】
[景别、机位、运动]。[动作]。[台词]。
画面里只有 X 一个人，没有文字。像电影里的一帧剧照，不是摆拍。

【风格参考（可选）】[摄影机 / 镜头 / 胶片]
```

纪律：

- 人物锁定只写一次，后面不再提（改写人物描述是变脸第一诱因）。
- 光源栏必须写「没有其他补光」，否则画面处处都亮、光比出不来。
- 风格参考只是一行文字锚点（摄影机/镜头/胶片名），不用配参考图；真正起作用的是缺陷描述。
- 元素要少：提示词里每多写一样东西，模型就多画一样，画面离摆拍更近一步。

## 第三步：五类缺陷速查（挑 2–3 类）

| 类 | 内容 | 写法要点 |
|---|---|---|
| 1. 光 | 强光「溢出」：高光周围一圈柔光；胶片上带红橙色光晕（Halation）；局部过曝 | 高光边缘干干净净是最明显的假 |
| 2. 镜头 | 眩光、暗角、边缘轻微变形、色散（颜色在边缘错开一点）；焦外光斑有形状，不同镜头形状不同 | 需画面里先有光源才成立 |
| 3. 介质 | 胶片颗粒（每帧都在变）、数字机暗部噪点、漏光 | 完全光滑 = 电脑画的 |
| 4. 焦点 | 焦点只在一个很薄的平面上，其余皆虚；跟焦时焦点轻微「追」一下 | AI 爱把所有东西画清楚，这是破绽 |
| 5. 空气 | 大气透视：越远越灰、越淡、越偏蓝；远景加一层雾、扬尘、热浪 | 远景和近景一样清楚，空间就是平的；巨物尺度感靠这层空气 |

场景速配（什么场景放什么光、写什么缺陷）：

- 胶片光晕：放霓虹、警示灯、路灯 → 写「高光周围红橙色光晕」
- 镜头眩光：放车灯、探照灯、太阳直射镜头 → 写「横向眩光、光斑」
- 漂亮焦外：放背景里的小灯点、指示灯 → 写「浅景深、焦外光斑」
- 轮廓光：放低角度逆光 → 写「头发边缘的暖色轮廓」
- 巨物尺度感：放白天外景 → 写「远景发灰、偏蓝、变淡、扬尘」

## 完整案例（作者原文，可直接改用）

反面写法：「电影感，8K，超高清，超写实，大片质感，一位老科学家在地下实验室里盯着电脑屏幕，神情震惊。」——出来的是「AI 科学家」标配：白大褂、白头发、夸张表情、处处都亮。

正面写法只用两盏光——屏幕冷光从下往上、台灯暖光从侧面，脸上一半冷一半暖：

```
【人物锁定】
角色B：五十多岁的欧洲男性科学家，深棕色旧呢子大衣，浅蓝衬衫，金属细框眼镜，胡子花白。普通长相，皮肤有皱纹和真实纹理，神情疲惫。

【光源清单】
没有窗户的地下实验室，四周很暗。
主光：他面前一台监视器的冷青色屏幕光，从下方照在他脸上。
辅光：画面右侧桌角一盏老式台灯，暖橙色，只照亮他半边脸。
背景深处有几个红色和绿色的设备指示灯小光点。
没有其他补光。

【缺陷清单】
光比很大，脸一半冷青一半暖橙，暗部保留细节，不要磨皮；
背景的指示灯在焦外变成柔和的圆形光斑；
眼镜片上有屏幕的微弱反光；细微胶片颗粒。

【调度与表演】
近景，50mm 镜头，平视，极浅景深，只有眼睛和眼镜框是清楚的。
他盯着屏幕，一只手把眼镜往下拉了一点，若有所思。
画面里只有他一个人，屏幕上没有可读的文字。像电影里的一帧剧照，不是摆拍。

【风格参考】ARRI ALEXA 数字电影机的肤色质感。
```

## 后期兜底（决定最后 10%）

颗粒、光晕这类缺陷由 AI 直接生成不稳定（颗粒糊、不随帧动、光晕成团）。更稳的做法：

1. 让 AI 生成不含颗粒/光晕/镜头瑕疵的**干净版**；
2. 后期再加：颗粒要逐帧变化才像真胶片；光晕 = 把最亮部单独提出、染红橙、轻微模糊后叠回；暗角与色散最后加，量要很小——看不出来但感觉得到。
3. 剪映、达芬奇、PR、AE、Nuke 都能做。

## 与 Playbook 01 的分工

- 01（20 句）管**皮肤与生活痕迹**：毛孔、红晕、碎发、生活场景。
- 02（镜头卡）管**成像链路**：这张图是被什么光、什么镜头、什么介质「拍」下来的。
- 人像特写先 01；画面带环境、夜景、强光源时叠 02。视频同理：首帧按镜头卡写，首帧对了，后面才不会一路塑料。
